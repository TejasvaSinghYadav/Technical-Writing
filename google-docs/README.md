# Google Docs

Google Docs is a cloud-based word processor in Google Workspace. It is used to create, format, share, and collaboratively edit documents from different devices.

## 1. Create and structure a document

- Start with a blank document or a template (report, meeting notes, manual, etc.).
- Add a clear title.
- Use paragraph styles: **Title**, **Subtitle**, **Heading 1**, **Heading 2**, and **Normal text**.
- Consistent heading styles make the document easier to navigate and allow an automatic table of contents.
- Insert tables, lists, images, footnotes, equations, and links where needed.

## 2. Formatting tools

Use the toolbar and menus to change fonts, size, colour, alignment, spacing, and paragraph styles. The slides also cover headers, footers, page numbers, Find and replace, spelling/grammar tools, autocorrect, and built-in templates.

## 3. Collaboration and sharing

Select **Share** to invite people by email or link. Choose the correct access level:

| Role | Permission |
|---|---|
| Viewer | Can view |
| Commenter | Can view and add comments |
| Editor | Can edit |

- **Comments:** attach feedback to selected text.
- **Resolve comments:** mark completed discussions as resolved.
- **Assign comments:** direct an action to a collaborator.
- **Suggesting mode:** propose edits without directly replacing the original text.
- **Live collaboration:** see other editors' cursors and changes.
- **Chat:** discuss the document with collaborators when available.

## 4. Version history

Google Docs saves changes automatically. Use **File → Version history → See version history** to inspect earlier versions, see who made changes, and restore an earlier version. Name important milestones such as `Draft`, `Reviewed`, or `Final submission`.

## 5. Insert content

| Need | Menu / feature |
|---|---|
| Image | Insert → Image (upload, camera, web, Drive, Photos) |
| Drawing | Insert → Drawing (shapes, arrows, simple diagrams) |
| Table | Insert → Table |
| Lists | Bulleted list, numbered list, checklist |
| Equation | Insert → Equation |
| Footnote | Insert → Footnote |
| Citation | Tools → Citations |

For code snippets, use a monospace font for short inline code. For larger code blocks, use a suitable add-on or a clearly formatted block.

## 6. Citations and bibliography

Open **Tools → Citations**:
1. Choose MLA, APA, or Chicago.
2. Add source details.
3. Insert in-text citations.
4. Generate a bibliography.

The lecture also mentions citation-manager integrations such as Zotero and Mendeley.

## 7. Export and publishing

Use **File → Download** to export formats including PDF, DOCX, ODT, RTF, HTML, and plain text (`.txt`). You can also use **Publish to the web** when a document is intended for public viewing. Check sharing and privacy settings before publishing.

## 8. Security and integrations

- Set document-level permissions carefully; remove access when it is no longer needed.
- Managed Workspace accounts may have organization-wide sharing rules and expiration controls.
- Docs integrates with Drive, Calendar, Meet, Forms, project-management tools, GitHub, and diagram tools.
- Google Apps Script can automate document-related tasks.

## 9. Good practices

Use consistent styles and templates, organize long documents with headings and a table of contents, assign appropriate reviewer roles, resolve old comments, and export important milestone versions. Avoid public links for confidential documents.

**When to use it:** Google Docs suits general documents and real-time collaboration. Doxygen is better for documentation generated from source code.
